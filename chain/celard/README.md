# celard — Celar chain node

`celard` is Celar's L1 node: a fork of the Cosmos EVM reference app (`evmd`) that
wires the `precisebank` module for a **9-decimal** native token
(`ncelar` / `acelar` / `CELAR`).

Build, devnet, verification, and MetaMask instructions are in the monorepo
README: [`../../README.md`](../../README.md).
